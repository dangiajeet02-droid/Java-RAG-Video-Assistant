An intelligent Retrieval-Augmented Generation (RAG) assistant that processes lecture videos, transcribes speech to text, and creates semantic vector embeddings for instant query retrieval.

##  Tech Stack
- **Backend:** FastAPI, Python
- **AI / Speech-to-Text:** OpenAI Whisper, Ollama (BGE-M3 / Llama 3.2)
- **Audio Processing:** FFmpeg
- **Frontend:** HTML5, CSS3, JavaScript

##  Key Features
- Automatic video-to-audio extraction via FFmpeg
- Accurate transcription using OpenAI Whisper
- Vector embeddings and similarity search via Ollama
- FastAPI backend connected to an interactive Web UI
